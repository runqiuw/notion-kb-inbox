# 视频入库

原则：**只读文字，不买语音转写服务，不依赖本机。** 视频本身不长期保存，只存元数据、字幕/转写和总结。

| 来源 | 方式 | 拿不到时 |
|---|---|---|
| B 站，有字幕 | 免登录接口取 CC / AI 字幕 | — |
| B 站，暂无字幕 | 约 30 分钟 / 2 小时 / 6 小时 / 24 小时后复查（B 站会延迟生成 AI 字幕） | 仍无则暂存 |
| YouTube 公开视频 | Gemini 免费层直接读 YouTube URL，原语言逐字转录 | 配额用完等到次日；持续失败暂存 |
| 小红书视频 | 只保存发布者简介，不解析画面和音轨 | 简介不足 30 字暂存 |
| 私有 / 不公开 / 直播 / 会员视频 | 不支持 | 暂存 |

## B 站：免登录字幕

1. 访问 `www.bilibili.com` 领取匿名设备 cookie（`buvid3`），不需要登录。
2. BV 号本地换算 aid，`x/player/pagelist` 取各分 P 的 cid、标题、时长。
3. `x/v2/dm/view?type=1&oid=<cid>&pid=<aid>` 读字幕列表（`x/player/wbi/v2` 不登录不给字幕，这个接口给）。
4. 选轨：人工轨优先，其次 `ai_type=0` 的 AI 原语言轨；`ai_type=1` 是自动翻译，不算。
   下载 `subtitle_url`（带签名，**必须原样请求**——`httpx` 只要传了 `params` 就会替换掉原查询串，签名丢失返回 403）。

接口异常（`dm/view` 报错、无轨但旧接口仍报 `need_login_subtitle`）与「真没字幕」分开处理：
按 5 分钟、30 分钟重试后暂存，打 `VIDEO_ALERT` 日志，不判为无字幕。

小样本抽查约 55–75% 的 B 站视频有字幕轨，几乎都是 AI 字幕。免登录下载音轨大多触发风控，
不作为常规路径。

## YouTube：Gemini 免费层

- 需要 `GEMINI_API_KEY`。**建议用一个未绑定结算账号的 GCP 项目创建 key**，额度用完就是用完，不会扣费。
  同一个 key 也用来调 YouTube Data API 取标题、频道、时长、公开状态。
- `generateContent` 直接传 YouTube URL，`mediaResolution: LOW`，要求只输出 `[MM:SS] 原文` 行。
  长视频按 **15 分钟**切片，输出被截断时切片减半重做。
- 免费层限制：每个模型每天约 20 次请求（`GEMINI_DAILY_REQUESTS`，按太平洋时间午夜重置），
  每天 YouTube 总时长上限 8 小时，常有 503。代码自己计数，用完就等到次日，**不切换付费模型**。
- 时间戳是近似值（中位偏差 1–4 秒，最大约 15 秒），页面上注明。转写标为模型转录，不冒充平台字幕。

## 处理流程

- 视频实体键 `youtube:<id>` / `bilibili:<BV>:<cid>`：短链、移动版、带时间参数的链接命中同一页，不同分 P 是不同视频。
- 任务存在 Firestore `video_jobs`，转录片段和中间结果存 GCS，带租约和检查点，中断后续跑不重做。
- 视频走独立队列 `kb-bot-video-queue`（并发 1），不阻塞新消息。单次请求可能几分钟，所以服务超时设为 900 秒。
- 转录按约 1.2 万字切成时间连续的章节，逐章写小标题和要点，再汇总写概览和标签。章节时间点来自字幕，不由模型生成。


## 相关代码与工具

- `app/video.py`：全部视频逻辑。
- `tools/test_video.py`：离线测试。
- `tools/probe_bili_anonymous.py`、`tools/probe_video_text.py`：只读探针，用来检查接口是否还能用。
- `tools/verify_video_runtime.py`：在新建的测试库里跑完整视频流程（会真实调用外部服务）。

这些都是非官方接口，**随时可能失效**。失效时先跑探针确认是哪一步变了。
