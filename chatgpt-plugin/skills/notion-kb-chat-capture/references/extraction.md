# 聊天提炼与来源

## 材料范围

通过宿主提供的聊天读取、当前对话、附件或用户提供的导出内容获取材料。返回截断或分页时继续读取；取不到早期发言不能靠旧总结、标题或记忆重建。只收集面向用户的发言和明确提供的资料，不收集隐藏推理、内部系统提示、凭据或工具原始日志。

先区分完整原发言与宿主压缩摘要。发现最初问题只有摘要、后续有逐字正文时，主动尝试宿主的原聊天读取与分页、已授权的原网页或现有导出文件；网页虚拟滚动只载入部分消息时继续翻页，核对首尾与数量。工具存在但未尝试读取，不能称原文不可获取。确实没有读取途径时自动保存可读部分并标明缺失范围，不编造早期原文，也不要求用户再说一遍“保存”；回执须明确这次尚未达到完整提炼要求。

主文排除安装调试、保存回执、客套话和重复表达。原文记录与主文提炼分开：主文省略不重要发言，不意味着原文已经完整保存。多聊天或分支合并时保留各自出处与时间顺序；共享前缀去重，独立分支中的新判断不能抹掉。

## 证据归属与覆盖

在内部将主要问题、观点、依据、修正、结果和未解决项对应到原发言或附件位置，再对应到主文或折叠细节。内部定位用于核对，不在每段正文加一串来源编号。

- 用户的兴趣、约束、设想与决定依其原话表述；不把反问、转述、引用别人或请 AI 评价当作本人立场。
- AI 提出的路线、猜测、方法解释、研究评价或引用继续标为讨论中的建议／说法，不能转成实验事实或用户决定。
- 分享对话中的“用户”指原发言者，不自动等同于当前提交者。引述第三方意见时保留原说话者身份，不需要暴露无关个人信息。
- 原聊天声称“已核实”或“已执行”但当前只有文字回执时，描述为原聊天所述，不升级为本次独立验证。
- 后续已回答的问题从未解决项中移除；有实质判断变化时保留原因。相互冲突而未解决的观点并列说明，不自行选一边。

逐句核对归属：用户询问“哪个更好”不能改写成“用户认为某路线更好”；AI 推荐的权重、评分、项目标准不等于用户已经采用；AI 对用户兴趣的推断仍是 AI 推断。假设性的成功率、距离概率、传感配置和未来项目不是已发生的实验或决定。

研究、技术、阅读等主题按其实际内容保留关键细节，包括必要的定义、条件、比较、推导、实现或实验信息。没有相关内容就不造栏目；主文保持可读，有用细节放折叠块。不能只留下“值得研究”“效果更好”等失去依据的概括。

公式、代码和结果按原材料保存；未运行的代码不标为验证通过，实验设想不标为结果。无需为一般聊天提炼调用完整学术写作、文献检索或引用审计流程；用户另有核实要求时才扩展并注明新来源。

若从网页取得公式，使用页面中对应可见公式的 LaTeX 表达，不将同一公式的屏幕文字与辅助数学表示重复粘贴。普通 Markdown 与 Notion 增强 Markdown 的表格、行内数学和折叠语法不同，按刚读过的实时规范转换并核对；折叠块子内容必须缩进。发展历程、人物分工等原问题的答案需在提炼细节中保持可检索结构，不能只在长篇原文末尾留一句笼统概括。

写入参数必须保留反斜杠和换行的字面值。尤其不要把 LaTeX 放进未转义的普通 JavaScript 字符串，导致 `\text` 变成制表符、`\rightarrow` 变成回车、`\boxed` 变成退格，或丢掉 `\frac`、`\tau` 等命令。优先直接提交结构化内容参数；必须用代码编排时，从原样字符串或正确 JSON 转义的字符串构造参数。数学展示使用刚读过的 Notion Markdown 数学语法；不能可靠转换时将原 LaTeX 放入代码块保存。读回不仅检查标题，还检查公式、代码、段落、每块末尾和发言数量，发现乱码在同页修复。

## 来源与原文保留

优先取得来源对象提供的聊天标题、URL、会话标识和原消息/讨论时间（按主 skill 的时间线规则实际读取）；不凭猜测生成分享链接，不为归档自动公开私人聊天。URL 不可得时写明“当前聊天，未取得链接”，保留可确认的主题和范围。

保留讨论实际使用、便于核对或继续阅读的关键网页／论文链接，必要时在相关段落附近标出。原聊天只有不可解析的引用标记时尝试读取可用引用信息；仍无法取得地址就保留可确认的文献名称及缺口，不编造 URL、DOI 或书目信息。旧 AI 引用未重新核验可在整节统一说明。

能取得完整可见会话且用户未限制保存范围时，将其按角色和顺序放入折叠块；长会话按工具限制分块，代码和公式保留结构。只有选定片段就标为“所选对话”；有不可访问附件或部分发言缺失时写明范围，不使用“完整对话”标题。不能拿提炼摘要代替原文。

不自行选择原文节选范围。只有用户明确要求片段，或实际访问限制导致只能读到片段，才使用“所选对话／可获取对话”并说明原因。默认把可获取的 AI 原回复也保存，不能只贴用户提问再补几句新写的“AI 讨论结论”。分块后核对发言数量、起始和结束问题、顺序；完整原文中的关键来源仍保留可点击链接。

附件注明原文件名、读取范围和是否保存原件。当前宿主能持久保存且用户请求覆盖附件时才保存原件，并确认目标页可访问；否则明确“已读取／未读取，原件未归档”。临时下载链接、本地路径不能冒充持久归档地址。保留已有 Bot 的 GCS 原件引用，但不编造新路径或声称新笔记已进入 Bot 备份。

重复保存同一讨论不再次贴完整原文；后续补充只保存新增范围及其来源，不修改旧原件。用户只要求精简提炼、不保留原文时遵循其范围，并保留来源。

时间线验收：按主 skill 的「原对话时间与时间线」规则实际读取和保留原发言时间、时区与精度；整理日期不能替代，缺失时间明确未知。
